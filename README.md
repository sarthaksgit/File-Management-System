# Automated File & System Utility Script

A lightweight, automated Bash utility script designed for streamlined directory navigation, automated file organization, and log inspection.

---

## Features

* **Automated File Organization:** Instantly scans a target directory and autonomously categorizes files into structured folders (`Images`, `Documents`, `Scripts`, `Archives`, and `Others`) based on their extensions.
* **Automated Log Inspection:** Scans system or application log files to automatically count error/warning occurrences and extract recent critical entries.
* **Streamlined Directory Navigation:** Built-in shell utilities for fast directory traversal and file system management.

---

## Getting Started

### Prerequisites
* A Unix/Linux, macOS, or WSL (Windows Subsystem for Linux) environment with a Bash-compatible shell.
